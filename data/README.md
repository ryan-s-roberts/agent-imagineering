# Public development inputs

`property-management/` is an unmodified copy of the Property Management directory
from [DwellyOrg/HackatonPublicCases](https://github.com/DwellyOrg/HackatonPublicCases/tree/main/Property%20Management),
pinned to commit `9bcdca585955dfb930005ed742572606e68f5688`.
`property-management-provenance.json` records every file's hash and the dataset
fingerprint. `UPSTREAM_README.md` preserves the upstream usage description.

These public cases are development material. This copy is not an untouched holdout.
Future private/unseen data should live outside this repository and be supplied via
`--input-dir`; do not place it in this tracked development directory.

Input layout and unseen-run instructions: [input directory contract](../docs/input-format.md).
